AWS Access Troubleshooter：看見拒絕請求的授權脈絡

What's New：2026-11-17；技術文件目前標示 public preview

AWS 新公告介紹 Access Troubleshooter，可透過拒絕訊息的 authorization ID 查詢請求脈絡與政策評估，不只看到某個拒絕政策 ARN。文件目前列出多數 IAM API，並說明服務與區域逐步推出；不能推論所有 AWS 服務已全面支援。

一般實務影響

可區分明確拒絕、未取得允許，以及條件不符。診斷應先確認拒絕是否符合預期，再決定要改請求、身分或政策。

具體建議

先以測試帳號的已知拒絕案例試用，記下 Region 與 authorization ID，交由有相應唯讀診斷權限的人查核。別為消除錯誤擴大權限或移除既有防護。

操作界線

  • API 為 GetRequestAuthorizationDetails；需要 iam:GetRequestAuthorizationDetails，且查詢與拒絕發生在同一 Region。
  • 資料保留 24 小時，寫入為非同步；結果反映拒絕當下的政策，不一定是現在的設定。
  • 不是每次拒絕都有 ID；未支援 API、過大授權內容、匿名或服務代呼叫等情境可能沒有。
  • 跨組織時只回傳自己組織的內容，不是跨組織完整政策檢視器。

本期保留公告與文件狀態差異，不把 11/17 公告解讀為 GA。診斷輸出可能包含帳號、資源與條件資訊，應留在受控管道。

值得試 · AI / Coding Agent

GPT-6.2 Astra／Sol 發布：以成本與任務品質一起驗收

發布：2026-11-17；API：gpt-6.2-astra / gpt-6.2-sol

OpenAI 推出 GPT-6.2 Astra 與 Sol，提供於 ChatGPT Work、Codex 與 API。Astra 著重複雜專業工作，Sol 偏日常效率；官方報告程式與文件產出改善，但實際效益仍需用自己的工作負載比較。

一般實務影響

較低單價或較少輸出 token 不保證每個任務都更便宜。工具呼叫、重試、人工修訂及驗證成本都應納入。

具體建議

固定一批程式修補、資料轉換與文件任務，保留舊模型基線，分別測 Sol 與 Astra。除正確率與耗時，也測檔案缺漏、工具不可用時是否明確回報，不只看成功案例。

Copilot Evals 公開預覽：對 skills、agents、MCP 跑重複測試

公告：2026-11-17；階段：public preview；引擎：Vally

GitHub Copilot Evals 可為 skill、custom agent 或 MCP tool 建立並執行可重複的行為測試，比較客製化前後的結果。支援 VS Code、Copilot CLI 與 Copilot app 的對應擴充／外掛；每次執行前需核准。

一般實務影響

把「這次回答不錯」轉成可重跑的檢查，但工具存在不等於已涵蓋所有資料正確性、權限及安全情境。

具體建議

先用無正式憑證的測試專案，準備正常、缺資料及工具失敗案例，明訂期望產出與不得發生的副作用。確認試跑安全後再納入日常回歸，暫不直接當正式部署的唯一關卡。

官方列示 Copilot Individual、Business、Enterprise 可參與預覽。評測工作負載可能真的呼叫工具，因此「執行測試」仍須限制資料與外部操作範圍；本報告沒有安裝或執行外掛。

官方來源：GitHub Changelog · Copilot Evals public preview
