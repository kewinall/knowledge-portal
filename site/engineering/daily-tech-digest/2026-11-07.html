Security Hub 新增組織級 SBOM 清冊

公告：2026-11-06 · Security Hub Essentials · 需啟用 Inspector

AWS 新增軟體物料清單（SBOM）清冊，整合 Amazon Inspector 對 EC2、ECR 映像及 Lambda 的套件資訊，可依套件版本、帳號與區域查詢，並透過 API 存取。

一般實務影響

發現套件漏洞時，可先定位受影響資產，再分派修補工作；但清冊完整性仍取決於 Inspector 實際覆蓋，不能把未列出的資產當成安全。

建議動作

先核對 Inspector 的資產與區域覆蓋，再挑一個已知套件名稱／版本，驗證清冊能否找回預期資產。本項是功能與覆蓋檢查，不代表已發現入侵。

最小驗證清單

  1. 選定測試帳號與區域，列出預期納管的 EC2、ECR、Lambda。
  2. 比對 Inspector 覆蓋及清冊結果，區分缺漏、未支援與尚未掃描。
  3. 以已知套件／版本搜尋，人工抽核一筆實際依賴。
  4. 記錄清冊更新時間與權限範圍，讓漏洞分流可重做。

此功能包含於 Security Hub Essentials，公告稱不另收此功能費用；不表示 Inspector、Security Hub 或相關資源整體免費。導入前仍需核對所用方案與計價。上述步驟是建議，未操作任何雲端帳號。

BigQuery Graph 的 GQL 查詢擴大支援隨用隨付

Release notes：2026-11-06 · 計價支援更新

BigQuery 11/6 更新紀錄新增 Graph GQL 查詢的 on-demand pricing 支援。現行文件也列出 Enterprise／Enterprise Plus reservation 選項；本次重點是計價方式，不是 Graph 首度推出。

一般實務影響

原本想先驗證關聯查詢、尚未配置固定容量的團隊，多了一條評估路徑。這不代表隨用隨付一定便宜，資料規模與查詢模式仍決定成本。

建議動作

用小型非敏感資料做供應鏈或事件關聯 PoC，先確認結果正確，再比較相同查詢的耗用、延遲與兩種計價方式。沒有圖查詢需求時可暫不導入。

先驗證價值，再比較成本

  • 正確性：用人工可核對的關聯與路徑，檢查重複邊、缺漏節點及結果。
  • 效能：保持輸入資料與查詢一致，記錄延遲及服務回報的用量。
  • 經濟性：分別估計低頻探索與穩定高頻查詢，不用單次測試推估全部月費。

Release notes 這項更新未在本報告被解讀為新的 GA 宣布。Graph 可用性、配額與計價細節仍以當下官方文件為準。

Google Cloud A5X 正式可用

10/21 官方文章於 11/6 更新 A5X GA 狀態。這是基於 NVIDIA Vera Rubin NVL72 的裸機 GPU 執行個體；大型 AI 工作負載可核對區域、配額與供應再評估，一般 ETL 或小型 Agent 不必跟進。
