PostgreSQL 14 到達社群支援終點

生命週期節點：2026/11/12；適用 PostgreSQL 14

變化

官方支援政策將 PostgreSQL 14 最終版本日期列為 11/12。這是社群維護期限，不等於服務會自動停止。

實務影響

繼續使用舊主版本，將失去後續社群安全與錯誤修補；託管服務的延長支援及費用要另查供應商。

建議

先盤點主版本、擴充套件與備份還原能力，排定升級至受支援版本。不要只升 14 的 minor release 就當作延長生命週期。

適用邊界

主版本升級需依官方程序使用 pg_upgrade 或匯出／匯入，先在副本驗證應用相容性與回復方案。本期不將生命週期提醒當作新的漏洞公告。

AWS Emulator：將 AWS API 測試移到本機

發布：2026/11/11；適用 AWS Emulator，公告未列固定版本號

變化

AWS 推出本機及 CI 可用的 Emulator，讓既有 SDK／CLI 呼叫改送本機端點，無需部署或 AWS 帳號。

實務影響

適合 Coding Agent 與測試套件快速回饋；每個實例有獨立 port、keys 與記憶體狀態，降低平行測試互相污染。

建議

挑一條小型 DynamoDB 測試流程試用，明確設定測試端點與 Emulator credentials；正式部署前仍以真實 AWS 做整合測試。

適用邊界

未實作的操作會回 501 Not Implemented，記憶體狀態在停止後消失。先查 fidelity report，不把模擬成功視為 IAM、網路與全部雲端行為已驗收。

持續觀察

Lambda MicroVMs 新增 x86 架構

發布：2026/11/11；適用 Lambda MicroVMs x86 images

變化

建立 MicroVM image 時可選 x86 或 Arm，既有 x86 工具與相依套件可降低移植成本。

實務影響

對 AI 程式碼執行環境、CI runner 與互動開發工具，提供另一個具 VM 層隔離與狀態保存的執行選項。

建議

若現有沙箱已符合需求，暫不遷移。需要既有 x86 binary 時，再以單一工作負載比較啟動、恢復、網路政策與費用。

適用邊界

本次是 CPU 架構支援更新，不是所有區域都有：香港、馬來西亞、泰國及西班牙不包含在此 x86 推出範圍。建置 image 前核對目標區域及服務限制。
