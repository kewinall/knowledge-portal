01
需檢查 · 資安／台灣

Red Hat Quay：先核對修補版本與映像完整性

TWCERT/CC 2026-11-27 · CVE-2026-110697／CVE-2026-123710

TWCERT/CC 通報兩項 Red Hat Quay 弱點，可能危及機器人帳號憑證與私有映像的完整性。這是容器登錄服務的問題，並非所有 Kubernetes 叢集都受影響。

一般實務影響

共用登錄庫若遭濫用，CI/CD 和叢集可能取得非預期的映像。只看 tag 沒有變動，不足以證明映像內容未被替換。

具體建議

先盤點自管 Quay 的版本與對外入口，依原廠公告採用相應修補版；若有異常跡象，保留稽核紀錄，按事件流程處理憑證並核對部署映像的 digest。

驗證與限制

原廠列出的修補版例：3.18.3、3.17.7、3.16.7；其他分支請逐一對照兩份公告。Red Hat 說明 Quay.io 已修補該機器人帳號問題，自管部署仍要自行核對。

官方來源：TWCERT/CC · 台灣通報Red Hat · CVE-2026-110697Red Hat · CVE-2026-123710

Managed Airflow：Java Beam 卡住先查映像與 worker 設定

2026-11-26 公告 · 11/25 起新修補映像改變預設 · Gen 2／3

Google 公告部分 Managed Airflow 工作用到 Apache Beam Java operators 時，可能因 OpenJDK 緩解用的 JAVA_TOOL_OPTIONS 而停滯或死鎖。包含已修補 OpenJDK 21 的新版映像不再自動設定這個變數。

一般實務影響

如果 Python 工作正常、Java Beam 或 Dataflow 提交卻卡住，應先把 Composer 映像與 worker 的 Java 設定納入排查，不只檢查 DAG 本身。

具體建議

先在測試環境升到官方列出的已修補映像，再按指南清理舊的手動緩解設定。挑一條 Java Beam DAG 驗證提交、完成、輸出與逾時告警。

驗證與限制

Gen 3 門檻：composer-3-airflow-3.3.1-build.10、composer-3-airflow-3.2.2-build.14 或 composer-3-airflow-2.11.1-build.27；Gen 2：composer-2.18.2-airflow-2.11.1。各分支可採後續修補版。不要在未修補的映像上直接撤下緩解。11/26 同時公告了 Agentic upgrade check，可先產生 DAG 相容性清單，仍要用實跑驗證。

官方來源：Google Cloud · Airflow 11/26 版更

BigQuery Storage API v1beta1 退場，先確認實際呼叫版本

2026-11-25 公告 · 2027-08-31 關閉 v1beta1

Google 公告 BigQuery Storage API v1beta1 將於 2027-08-31 關閉。11/20 起已先將存取限制在指定歷史期間內有活躍使用紀錄的專案；到期後舊端點會回傳 NOT_FOUND。

一般實務影響

老版 Spark、Beam、Trino、ODBC/JDBC 套件或自行呼叫 gRPC 的程式，可能只在特定讀取模式使用舊 API。SQL 查詢成功，不代表舊 Storage API 已移除。

具體建議

盤點套件鎖定版本及直接呼叫的服務名稱，先遷移一條有代表性的讀取流程，再驗證筆數、欄位型別、吞吐、重試與排程執行。

驗證與限制

這次是 Storage API v1beta1 退場，與 BigQuery cross-cloud connections 的 GA 是兩件事。直接呼叫的應用改用 google.cloud.bigquery.storage.v1；連接器依各自支援版本與實際請求驗證。

官方來源：Google Cloud · 停用公告Google Cloud · Storage API

短訊｜持續觀察：受管 Spark on GKE v2 進入私有預覽

Google 11/27 公告可在 Standard GKE 上執行下一代受管 Spark 工作負載，現階段須經專案核准才可使用，尚非全面開放。不必為此重排既有 Spark 移轉。

若已有 Standard GKE 且具試用資格，可先用小型批次量測啟動時間、資源隔離與失敗重跑；公告未承諾 Autopilot 支援。

官方來源：Google Cloud · 11/27 發布紀錄
