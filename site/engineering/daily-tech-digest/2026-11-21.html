01
優先盤點 · Security

GitLab 緊急修補：先確認自管版本與安裝方式

公告：2026-11-20 · CE/EE 19.6.1、19.5.8、19.4.10

GitLab 發布 Critical patch，修正 bundled Ruby 的安全問題，包含 CVE-2026-132825 字串處理堆積緩衝區溢位。官方要求 Self-Managed 儘速更新；GitLab.com 與 Dedicated 已完成修補，使用者不必自行升級。

一般實務影響

自管平台應優先盤點暴露面與版本，不要把 SaaS 已修補誤解為自建主機也安全。此處僅提供防禦性處理方向，未判定任何特定主機已遭利用。

具體建議

確認版本、套件或原始碼安裝方式；先驗證備份可還原，再依必要升級停靠版本規劃維護。完成後檢查登入、Git 操作與一個 Runner 測試工作。

驗證與限制

官方 Linux packages 與容器映像包含修補後 Ruby；自行編譯者須同步處理 Ruby runtime。不要只更新 GitLab 程式碼而沿用有問題的執行環境。從舊版升級仍須遵循官方 upgrade path，不宜直接跳版。

官方來源：GitLab · Critical Patch Release
02
值得試 · Cloud / FinOps

AWS 即時估價 API：讓設計先帶著成本假設

公告：2026-11-20 · GetUsageLinesEstimatedCost · GA

AWS Pricing Calculator 新 API 一次接受最多 500 筆用量，回傳各筆及總估價，不必把估算存入帳號。可選公開 On-Demand、折扣後，以及含 Savings Plans／Reserved Instances 的費率。

一般實務影響

架構工具或 AI agent 可以在部署前取得成本回饋；估價結果不是實際帳單，也不是購買、開機或承諾支出的授權。

具體建議

以一個固定 workload 與既有估價交叉比對，明確保存區域、用量單位、費率類型及時間。先讓 agent 提出比較結果，保留既有人工核准與部署界線。

驗證與限制

官方列為 GA，除 AWS GovCloud（US）及中國區域外可用，API 無額外費用。比對時保持相同折扣假設，避免把公開定價與承諾用量優惠混成同一基準；無法估價或輸入缺漏的項目須另外列出。

官方來源：AWS · Pricing Calculator API

短訊｜GitLab 19.6 的 LOCAL_CA attestation

19.6 新增 LOCAL_CA 與 Self-Managed／Dedicated 支援，也讓私有及內部專案能產生 provenance。LOCAL_CA 不把證明送往公共 Sigstore／Rekor，適合評估非公開專案的供應鏈驗證。

限制：Ultimate、Experiment、feature flag 預設停用，官方明示尚不適合正式環境。現有 glab attestation verify 只驗 SIGSTORE，不驗 LOCAL_CA。

建議：只在隔離測試專案評估，先釐清 CA 信任、憑證輪替及實際驗簽工具，再考慮部署閘門。來源證明不能取代弱點掃描或功能測試。
