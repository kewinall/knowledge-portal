PostgreSQL 新一輪安全修補已發布

發布：2026-11-12｜版本：18.7、17.12、16.16、15.20、14.25

變化

官方一次修正 52 項安全漏洞與超過 140 項錯誤。這是昨天支援期限提醒之外，已實際發布的新修補。

實務影響

資料庫安全與資料正確性都需關注；使用受影響索引或增量備份者，不能只換 binary 就結案。

建議

盤點主版本，在副本測試後安排 minor 更新與重啟；託管服務另確認供應商上架時程。14.25 是 14 最終版，仍須規劃主版本遷移。

更新後檢查

依官方 upgrade notes 判斷 GIN、pg_trgm GiST 與無長度 bpchar B-tree 索引是否需 REINDEX；使用增量備份者，更新後先建立新的完整備份。Minor 更新一般不需 pg_upgrade 或匯出／匯入。

持續觀察：同日的 PostgreSQL 19 RC2 仍是候選版，不用它替代正式環境修補。

Gemini Decisions API：把分類與路由變成明確選項

發布：2026-11-11｜模型：gemini-decision-1｜Gemini API / Google AI Studio

變化

新 API 對多模態輸入回傳是非、選項與評分機率，而非自由生成文字；同一份輸入可評估最多 1,000 個問題。

實務影響

適合 Agent 工具選擇、查詢路由與文件品質檢查。輸出較容易交給程式判斷，但信心分數並不保證每個領域都可靠。

建議

先用非敏感、已標註樣本比較誤判率、延遲與成本；低信心結果轉人工或既有流程，不直接讓分類結果取得執行權限。

適用邊界

官方範例採 v1beta；Google Cloud 支援仍列為即將推出，不能當作 Vertex AI 已可用。先測閉集分類，不拿它取代長文生成或獨立的權限檢查。
