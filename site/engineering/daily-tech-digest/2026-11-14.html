FortiManager：先核對未驗證 FGFM 命令執行風險

台灣警訊發布／更新：2026-11-13

TWCERT/CC 新公告 CVE-2026-126261：未經身分驗證的攻擊者可透過特製 FGFM 封包存取相關連接埠並執行程式碼或命令。這是集中管理設備的風險，應優先於一般功能升級處理。

一般實務影響

管理平台一旦遭入侵，可能影響受管設備與設定可信度。先確認是否實際使用受影響版本；未使用 FortiManager 者無須因這則消息變更其他產品。

具體建議

盤點版本與 FGFM 可達來源，依原廠支援的升級路徑安排修補；變更前備份組態、驗證受管設備相容性，完成後讀回版本與管理連線。限制管理介面暴露是風險降低措施，不等於完成修補。

需檢查

AgentCore Runtime V2 成為新建預設：部署要固定版本

AWS 發布：2026-11-12

AWS 宣布指定區域的新建 Amazon Bedrock AgentCore Runtime 預設改用下一代 V2；既有 Runtime 不會自動遷移。V2 從已初始化 Agent 的快照恢復 Session，閒置時縮至零，每個 Session 仍使用獨立 Firecracker microVM。

一般實務影響

同一份未指定平台版本的部署設定，新建結果可能與既有 Runtime 不同。這影響初始化假設、啟動延遲、工作階段與資源測試，不能只看部署成功。

具體建議

檢查 IaC／API 是否明確設定 platformVersion；需維持現況的新建環境指定 V1，要驗證下一代則指定 V2。先在測試環境檢查初始化、外部連線、Session 隔離、閒置後恢復及成本，再遷移既有 Runtime。

適用範圍與限制

  • V2 支援最高 8 vCPU、32 GB 記憶體及 10 GB 容器映像。
  • 官方列出的新預設區域包含東京、新加坡、首爾、雪梨等；未列為預設的區域仍需核對服務支援，不能推定全球同時切換。
  • 官方 2 GB 映像的啟動 P75 低於 2 秒及最高 68% Session 記憶體計費減少是特定測試／工作型態結果，不是所有部署的承諾。

本期新增焦點是 11/12 的預設平台變更，不重複介紹先前的 Web Search API 或 Nitro Sandboxes。建議屬工程判斷，未對任何 AWS 環境進行操作。

官方來源：AWS · 新 Runtime 預設公告
03
值得試

Gemini 4 Hydrogen：以同一批任務測執行型 Agent

原始發布：2026-11-12；官方頁更新：2026-11-13

Google 推出 Gemini 4 Hydrogen，定位為日常程式開發與 Agent 工作的快速執行模型；官方宣布涵蓋 AI Studio、Gemini API、Gemini app 等入口。它與昨日的 Gemini Decisions API 是不同發布，不應混為分類端點的版本更新。

一般實務影響

可用於驗證工具呼叫、程式修改與資料整理的成本／延遲取捨。模型變快不代表端到端流程更可靠，也不代表可取消權限檢查、測試或人工核准。

具體建議

挑選一組去識別的 SQL／ETL 說明、測試修復與工具失敗案例，與現有模型盲測正確率、總耗時、重試及每個成功任務成本。先做非正式環境試用；未達既有品質門檻就維持現有配置。

版本與驗收重點

  • 適用模型：Gemini 4 Hydrogen；實際入口、配額與可用性依帳戶和產品核對。
  • 提供 low、medium、high（預設）與 xhigh 思考層級；比較時固定層級及工具條件，避免把不同設定的結果直接相比。
  • 官方公布的效能與安全測試是廠商測量，不是私有工作負載驗收。試用應包含工具超時、空搜尋結果與無權限操作等失敗情境。

持續觀察：長任務品質、重試成本與限額。尚不建議僅因模型新發布，就替換既有正式 Agent。

官方來源：Google · Gemini 4 Hydrogen 官方發布
