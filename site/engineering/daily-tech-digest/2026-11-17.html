Apache HTTP Server：台灣發布 HTTP/2 遠端執行風險提醒

上游修補：2026-11-11；NICS 提醒／Ubuntu 更新：11-16

國家資通安全研究院 11/16 提醒 CVE-2026-119618。Apache 的 mod_http2 同步處理缺陷可能導致遠端程式碼執行；上游列示 2.4.55–2.4.70 受影響，2.4.71 已修補。這是台灣新增提醒，不是把 11/11 版本當成今天才發布。

一般實務影響

除網站主機，也應盤點反向代理、容器映像及內嵌 httpd 的設備。發行版可能回移較新模組，因此主程式版本較舊不等於不受影響。

具體建議

先確認實際套件、mod_http2 載入及 HTTP/2 設定，再依原供應商管道更新；重啟後驗證版本、網站健康與 HTTP/2 連線。無此元件者不需為此項全面換版；設備使用原廠修補，不自行替換其內嵌套件。

GitHub Copilot：11/16 模型退役已生效，留意例外

最初預告：2026-10-15；實際生效公告：2026-11-16

GitHub 確認 Claude Opus 4.8、Claude Opus 5 與 GPT-5.6 Terra 在多數 Copilot 體驗退役。這不是昨日摘要的 12/14 六款模型預告，而是另一批模型已到切換日。

一般實務影響

模型選單與固定模型工作流程可能改變。替代模型受組織政策限制；功能可用不代表任務品質、延遲與額度消耗完全相同。

具體建議

核對選單、整合與政策，以小型固定測試集驗證替代模型的修改正確性、工具呼叫及延遲。無須手動移除退役模型，也不應為了切換任意放寬企業政策。

替代與例外分開看

  • Claude Opus 4.8／5：官方建議 Claude Opus 5.5。
  • GPT-5.6 Terra：官方建議 GPT-6.1 Sol 或 GPT-6 Luna。
  • Claude Opus 4.8 仍提供給個人年繳 Copilot 訂閱者。
  • Claude Opus 5 雖移出選單，仍可透過既有授權作 runtime refusal fallback；原企業模型政策照常適用。不能因此說它在所有執行路徑完全不可用。

Business／Enterprise 的建議替代模型通常依預設模型啟用政策開放；若管理員關閉全域預設或明確停用模型，仍需核對管理設定。

官方來源：GitHub Changelog · 11/16 生效與例外
