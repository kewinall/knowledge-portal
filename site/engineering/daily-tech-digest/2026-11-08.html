P1 · 需檢查 · 成本生效提醒

部分舊版 OpenSearch 延長支援附加費生效

變化：AWS FAQ 指定的舊版本，自 2026-11-07 起至 2027-11-07，延長支援附加費等於 instance 成本，並加在原費用之上；儲存費用不受這項調整影響。

適用：Amazon OpenSearch Service 的 OpenSearch 1.0–1.2、2.3–2.9，以及 FAQ 明列的部分舊 Elasticsearch 版本。這不是所有版本或整張 AWS 帳單翻倍。

建議：先盤點 domain 版本與帳單。若落入指定範圍，評估升級至 Standard Support 版本，先測試相容性、快照還原與升級路徑。

P2 · 值得試 · 新版本

AgensGraph 2.18.6.1：GQL 與圖查詢權限更新

變化：11/7 的開發商公告介紹部分 ISO GQL 子句、圖形子查詢，以及 Cypher 寫入與部分 pattern matching 的列級安全政策（RLS）執行改善。

適用：AgensGraph 2.18.6.1。這是 PostgreSQL 官方新聞站的相關開源專案公告，不是 PostgreSQL 核心版本發布，也不代表已完整實作 ISO GQL。

建議：先用代表性圖查詢、不同角色與拒絕存取案例驗證，再決定升級；未使用 AgensGraph 者不必為新功能更換資料庫。

升級前的必要檢查

  • 2.17 的資料目錄不能直接給 2.18 使用。先演練 pg_upgrade，或使用 2.18 的 pg_dump 匯出後還原。
  • 已在 2.18.6.0：公告指示更換 binary 並重啟；仍應先備份與測試。
  • RLS 改善可能改變既有查詢結果或寫入權限，須回歸驗證。不要把廠商測試效能當成自己的工作負載保證。
