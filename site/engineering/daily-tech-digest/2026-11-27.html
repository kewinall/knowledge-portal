需檢查 · 資安／台灣

Linux 核心 CVE-2026-99676：依發行版與核心套件核對

TWCERT/CC 2026-11-24 · Linux 核心 · 各發行版處置不同

TWCERT/CC 公告 Linux 核心網路子系統漏洞，列 CVSS 9.8。各發行版有自己的影響判定與修補版本，不能以通用核心版本或單一分數判定所有設備。

一般實務影響

一般 Linux 主機以及容器和 Kubernetes 的節點都應盤點。容器通常共用宿主核心，單獨重建應用映像不等於修到節點。

具體建議

先讀取正在執行的核心版本、CPU 架構及套件分支，再查發行版公告；有對應修補時以測試節點驗證、分批更新，必要時重啟並確認新核心已生效。

驗證與限制

把受影響、有修補、待供應商與不受影響分別記錄；受管節點依供應商的節點映像與維護指引，不直接套用另一發行版的版本門檻。

BigQuery 跨雲連線正式可用，先量成本與資料移動

2026-11-25 · BigQuery cross-cloud connections · GA

Google 將連 AWS、Azure 與 Salesforce Data 360 的跨雲連線轉為 GA，從所有 BigQuery 區域可用。在 BigQuery 側查詢時，能使用標準 BigQuery 容量以及部分標準 Omni 連線不支援的能力，例如 materialized views 與 UDF。

一般實務影響

這不是單純把運算留在對端。此方式會把讀取的資料帶入 BigQuery；啟用 caching 時會將檔案區塊快取於連線所在的 Google Cloud 區域，預設不啟用。

具體建議

先用一小批非敏感資料比較冷／熱查詢延遲、跨雲傳輸費與 slot 使用量；同時確認位置與權限，再決定是否啟用快取。

驗證與限制

若需求是不移動資料或須用其他引擎查遠端 Iceberg catalog，不要直接把這項功能當替代；分別對照標準 Omni 連線與 Lakehouse 的適用情境。

AWS ELB for Envoy GA：AWS 接手代理維護，設定仍由你負責

2026-11-25 · Elastic Load Balancing for Envoy · 14 個區域 GA

AWS 新增受管 Envoy 負載平衡類型，負責代理的配置部署、擴縮、Envoy 與作業系統更新；團隊仍提供自己的 Envoy 設定，也可接既有 control plane。Envoy Gateway 有專用 remote infrastructure provider。

一般實務影響

對自營 Envoy 的團隊，可少維護一組代理機群；但流量規則、憑證整合及服務層行為仍需測試。

具體建議

先挑一個非關鍵服務，比對路由、TLS、逾時、健康檢查、日誌、費用及故障切換，再決定是否移轉；先留舊入口做回復。

驗證與限制

首批 14 區域包括 Oregon、東京及新加坡，公告未列台北。既有 ALB 或 NLB 不需為此改型；先判斷是否真的需要自訂 Envoy 設定或 Gateway API 整合。
