01
先限範圍 · Cloud Ops

AWS SSM Runbook 可操作 Azure 與 Google Cloud

2026-11-23 · AWS Systems Manager Automation／Cloud Connector

AWS Systems Manager Automation 增加六個 Azure／Google Cloud Runbook 動作，可呼叫 API、檢查資源狀態或等待操作完成。AWS 公告支援以訂閱、專案、資源類型和標籤等條件鎖定目標。

一般實務影響

同一套維運流程可以跨雲編排並加入批次、核准、錯誤停損；但各雲資源的實際可操作範圍，仍取決於各自授權。

具體建議

先在非正式環境做唯讀盤點，核對所選資源清單和權限。要引入寫入時，先測單一非關鍵資源，保留人工核准及錯誤停損。

驗證與限制

進階流程可使用 aws:executeScript 的 Azure／Google Cloud SDK，Cloud Connector 提供短效憑證，不必將雲端金鑰寫入 Runbook。支援範圍以可建立 Cloud Connector 的 AWS Region 為準。

官方來源：AWS · SSM 公告AWS · 跨雲 Runbook 指南
02
先驗查詢 · Data Platform

BigQuery 查詢計費控管 GA：禁用隨用隨付前，先查 slot 配置

2026-11-23 · reservation_override_mode / disable_on_demand_billing GA

BigQuery 的兩項區域設定已正式可用，可限制查詢是否能覆寫分配的 reservation，或是否必須使用已分配的 reservation slots，而不能按查詢用量計費。

一般實務影響

限制隨用隨付（on-demand）可避免未預期的查詢計費，但缺少 reservation 分配的查詢可能直接失敗；這是排程可用性與成本控制的取捨。

具體建議

先在非正式專案的單一區域測試一批排程與互動查詢，記錄 reservation 歸屬、失敗與帳務差異。確認所有必要工作有 slot 配置，再考慮擴大。

驗證與限制

先保留原有設定，檢查組織層與專案層的實際生效值。官方指出 disable_on_demand_billing 為 true 時，未使用已分配 reservation 的查詢會失敗；不是所有查詢用量都消失。

官方來源：Google Cloud · BigQuery Release notesGoogle Cloud · Reservation 設定

短訊｜Copilot 雲端沙箱 11/23 起計費

GitHub 於 11/19 更新公告，指定 11/23 起生效。新雲端體驗適用於付費 Copilot 方案；雲端沙箱執行中的 compute 和 memory 可扣 GitHub 帳號包含的共享額度，超額依帳號的費率、預算與付款設定處理。這不是所有 Copilot 對話或本機 sandbox 同時加價。
