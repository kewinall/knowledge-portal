eMudhra：Microsoft 自 11/16 起移除剩餘根憑證信任

原文：2026-10-26；本輪公告更新：11-12；預定開始：11-16

MSRC 宣布繼 10 月措施後，從 11/16 起在產品與服務中移除剩餘 eMudhra 根憑證的預設信任。更新到達端點後，相關憑證鏈可能不再通過驗證；各產品推送與上游依賴不同，不能視為今天全部完成。

一般實務影響

瀏覽器、CLI、SDK 與映像可能使用不同信任庫。同一服務在某工具正常，不代表另一工具也會接受其憑證鏈。

具體建議

盤點相依站台與工具，核對信任庫更新和完整鏈；安排替換憑證及連線測試。隔離端點應依既定更新程序驗證，不以關閉 TLS 驗證或任意恢復信任處理錯誤。

版本與可用性界線

  • Edge／WebView2 經 PKI Metadata 元件推送；Windows 經自動憑證信任清單更新端點。
  • Azure Linux 映像更新預定從 11/16 起；相依映像仍須核對實際版本。
  • 公告預定 Azure CLI 2.93.0 於 11/16、VS Code 1.147.0 於 11/18 提供相應更新。本期未驗證這兩版已實際發布。
官方來源：MSRC · 11/12 更新與產品時程

GitHub Copilot：六款模型將於 12/14 退役

公告：2026-11-13；預定退役：2026-12-14；適用：Copilot 各使用體驗

GitHub 公布六款 Copilot 模型的退役安排，涵蓋 Chat、編輯、Agent 與程式碼補全。這是模型生命週期調整，不是今日服務中斷，也不是要求立即全面更換工作方式。

一般實務影響

固定模型選擇、整合設定與管理政策需重新核對。替代模型可用，不等於既有提示與任務結果完全一致。

具體建議

先找出仍使用退役模型的流程，再以同一測試集比較修改正確性、延遲與使用額度；確認管理政策允許替代模型，於期限前分批切換。

Azure Data Share：退役日期訂為 2029/11/12

加入 roadmap：2026-11-13；適用：snapshot-based 與 in-place sharing

Azure 公告 Data Share 將於 2029/11/12 退役，影響資料提供者、接收者及相關應用。官方沒有提供自動的一對一遷移路徑。

一般實務影響

分享權限、訂閱、排程與接收端行為需要共同規劃，不只是更換 ETL 工具。

具體建議

先建立 shares、subscriptions、schedules 與整合清冊。依資料來源評估 Fabric 外部分享或 ADF／Fabric Data Factory 複製；驗證權限、完整性、更新、監控與復原後才切換。目前不需停用正式資源。

替代方案依來源及使用情境選擇，不能視為功能等價。唯讀檔案查詢也不等於快照或分享生命週期管理。這是長期規劃訊號，不是緊急遷移通知。

官方來源：Azure Updates · Data Share retirement（578818）
